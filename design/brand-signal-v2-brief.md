# Dipole Brand Signal v2

当前蓝色的 Dipole logo 不如上一版自行设计的方案。请在现有 Dipole canonical 设计文件中新增一个 `Brand / Signal Mark v2` 评审区域，不要重建或修改现有产品页面。

为事件驱动的实时协作与 Agent 平台设计一套更有辨识度、成熟、克制的标识系统：包含横向 README 字标、方形应用图标、适合 16-24px 的单色小图标，以及浅色 README 背景下的展示。视觉应表达双端连接、事件流和持续协作；避免厚重、含义不清的对称轮廓，避免渐变和泛化的聊天气泡。保留蓝色作为主色，但让图形本身在单色和小尺寸时也清晰可辨。

在画布中标出色彩、最小尺寸与使用场景，并保持现有 Dipole 设计语言的克制排版。
